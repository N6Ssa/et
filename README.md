# ЭТ CTF

Красно-чёрный сайт с дождём из кода, анимацией разделов, пакетами спонсорства и демонстрационной формой заявки.

## Разработка

Исходники находятся в public/. Внешние зависимости не нужны. Требуется Node.js 22 или новее.

- npm run check — проверка ссылок, скриптов и ресурсов.
- npm run build — сборка статического сайта в build/.

Для локального просмотра используйте любой статический HTTP-сервер.

## Публикация

GitHub Actions публикует сайт в GitHub Pages после отправки изменений в main.

Адрес: https://n6ssa.github.io/et/

## Форма заявки

Форма — макет: проверяет обязательные поля и показывает демонстрационное подтверждение. Данные не сохраняются и никуда не отправляются. Для настоящего приёма заявок потребуется отдельный обработчик.
